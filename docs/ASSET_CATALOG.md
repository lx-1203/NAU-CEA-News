# 复用资产目录

复用包内以assets/qualified-assets.json为逐文件验收与SHA256清单，BUNDLE_MANIFEST.json核对全部打包文件。运行python scripts/verify_assets.py核对资产完整性；资产技术合格不等于取得公开再分发许可。

| 分组 | 数量 | 用途和状态 |
|---|---:|---|
| 小序整图表情动作 | 7 | 当前expressionMap实际使用的整图；不使用旧嘴层或拼脸 |
| 小禾整图表情动作 | 7 | 当前expressionMap实际使用的整图 |
| 固定声音参考 | 2 | 小序boy-v2、小禾girl-v2；SHA和参数在config/pipeline.json |
| 节目标识与校徽 | 4 | 当前演播室使用的标识和屏幕循环素材 |
| 启用转场 | 11 | v3透明WebM，实际生产使用 |
| 转场原画与参考图 | 22 | 与上述11组对应，作为后续修订参考 |
| 转场预览 | 11 | 与上述11组对应的MP4，便于预览挑选 |
| 角色原始参考 | 1 | 角色身份参考，不替代当前整图映射 |
| 采编参考 | 2 | 原HANDOFF.md与11月7日样刊；只借鉴形式，不作为新一期消息 |
| 合格新闻媒体示例 | 11 | 历史期已筛选原新闻素材，来源在examples/historical-media-sources.json；每日须重新采集当期素材 |
| 待确认新闻页 | 1 | 版式参考，尚未获用户定稿确认，不能据此声称新片获批 |

合计79份资产，其中参考与待确认项有独立状态。包内还包含播放器代码、制作代码和文档，它们不计入79份媒体资产。

透明WebM已满足现有视频生产。约1.54GB的11份ProRes MOV母版未放进轻量联网安装包；原机保存在assets/transitions/campus-sweep-v3/renders/各编号/transition-alpha.mov。复用包的library.json移除这些未打包的可选路径，避免误报缺失依赖。

不打包退役修图、旧嘴层、被拒绝的文字截图、未定稿新IP、密钥、缓存、模型权重和运行日志。模型按固定版本首次联网下载，约8.87GB；新闻原图/视频、音色和校徽不上传到新闻稿公开仓库。
