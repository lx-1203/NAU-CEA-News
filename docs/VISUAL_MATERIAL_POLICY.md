# 参考图与新闻配图准入规则

2026-11-09，Asia/Shanghai。用户直接要求：“更新规则参考图拒绝一切文字截图”。本条覆盖旧规范中允许原文截图入画的表述。

2026-11-10新增用户要求：“不要偷懒用自己画的SVG替代图片素材，拒绝你的任何偷懒”。下方新规则覆盖旧规范中允许自绘图形补素材的表述。

## 禁止以程序绘图替代图片

需要图片、照片、插画、LOGO或真实演示时，必须取得合格原始素材，或按任务要求使用相应图像生成/编辑工具。不得自行用SVG、Canvas、HTML/CSS、Pillow、Matplotlib画图、拼图标或做简化示意图顶替。将其转成PNG/JPG、录成视频、用于模糊底层，或标为“编辑整理/事实图”，同样不合格；LOGO改字也不例外。

不得以省事、省Token、赶工、矢量更清晰/可编辑、事实已核实、接口已存在或下载失败为理由降低要求。应继续核实其他来源、取得原资源或按任务使用图像工具；仍缺素材则如实标记缺素材/未完成，不能用替代品交差或宣称完成。

发布方原有图形资料按来源核验规则使用，自行绘图不得伪装成发布方原图。标题、字幕、要点和来源文字正常排版，但不能借此制作替代图片/LOGO。终检须实际核查每份素材的来源与制作方式，含LOGO、前景、模糊底和旧素材；旧审查通过不构成豁免，哈希/扩展名不能自动证明合格。

## 当前硬性编辑规则

参考图、预览、新闻配图、视频大屏及模糊铺底，一律拒绝文字截图，包括新闻/公告正文、论文页、GitHub Release/README说明、代码/日志、聊天记录以及以说明文字为主体的界面截图。官方来源、已核实或能证明首发，都不能成为入画例外。把截图放大、裁切、模糊、改名或录成滚动文字视频，也不能绕过此规则。

优先使用原新闻照片、真实产品/设备/现场画面、原视频中的真实演示，以及发布方图形为主的原始架构/流程/数据图。不得自行重绘图形来补缺图，不编造现场、数字或效果。图片里的正常标识和图示标签不等同文字截图；标题、口播字幕、要点与来源标注仍是正常版式内容。

文字截图只可留在内部核验存档，不能算合格配图，不能进入主画面或底层背景。来源不够时继续补找合格图像/视频，标记缺图，不能用文字截图凑素材。

规则已同步新闻制作skill与素材接口文档，执行时逐素材人工判断；当前程序的哈希/日期校验不等于自动图像内容识别，不声称已全面自动识别所有文字截图或程序绘图替代品。
