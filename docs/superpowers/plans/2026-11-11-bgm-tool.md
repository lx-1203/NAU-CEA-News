# 每日 BGM 工具实现计划

目标：自动更新曲库元数据，每轮使用完全部可用音频才重置；只临时下载选中曲，跨期保留 JSON 历史，成功或失败均释放工具缓存。

架构：pipeline/bgm_source.py 管来源，pipeline/bgm.py 管选择、混音及缓存生命周期；pipeline/render.py 接入正式生产，scripts/bgm.py 暴露复用命令。实现使用 Python 标准库和已安装 FFmpeg。

- [ ] 任务 1：tests/test_bgm.py 先测试两轮不重复、同一期重用、失败不计数、新增/删除曲目、历史迁移与状态损坏。运行 `python -m unittest discover -s tests -p test_bgm.py -v` 确认缺少功能，再实现 history/transaction，重复运行通过。
- [ ] 任务 2：tests/test_bgm_source.py 使用本机 HTTP 服务器测试 Range 单曲提取、不支持 Range 的临时整包、校验和错误、超限和异常清理；先失败再实现 bgm_source.py。运行 `python -m unittest discover -s tests -p 'test_bgm*.py' -v`。
- [ ] 任务 3：scripts/bgm.py 暴露命令，render.py 接入准备、混音、成功提交和 finally 清理。用短视频实测最终完整解码、音轨变化、转场静音和画面字节不变，失败不会消耗记录，结束缓存字节为 0。
- [ ] 任务 4：补 docs/BGM.md、默认 config/bgm.json、managed-files、skill 和 VERSIONING，检查 CLI 帮助；在完整回归中核对既有生产功能。
- [ ] 任务 5：Full 自查/OCR，冻结架构与技能 1.3.0，构建更新包，先检查远端其他窗口改动再合并发布。匿名下载和哈希复验；本机保留其他窗口改动并如实处理安装冲突，更新 TODO 和验收记录。

执行采用当前窗口内联开发，用户无需批准中间实现选择；发布前只推进测试支持的内容。
