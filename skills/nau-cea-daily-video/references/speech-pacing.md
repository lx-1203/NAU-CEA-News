# 固定音色的语速校准

项目用户于2026-11-09确认：小序自然男童声boy-v2、小禾自然女童声girl-v2不变，两人正文280–300字/分钟，数字和术语不要赶读。该数值是项目制作要求，不是国家统一强制标准。

配置权威：config/pipeline.json中的speech.pacing；语音参考、SHA、情绪参数和工作台合成基础rate保持原值。不要为让语速一致而换音色、变调，或只给两个主播设置相同倍率。

## 已接入的接口

`python -m pipeline.run render --edition <edition.json>`在每句转成PCM后、响度处理及字幕/动作排时前调用`pipeline.pacing.pace_for_render`。开启speech.pacing后，工作台新录音与显式复用外部WAV均走同一处理。保留`cue-xxx-unpaced.wav`、处理收据与完整源音频哈希；`normalization.raw_file`是变速后、响度处理前的文件，pacing.output_sha256对应该文件，不对应已增益处理的最终cue。

正常句优选295字/分钟，数字或术语句优选285；超出安全倍率时只在280–300内选更慢目标，不能裁口播或删句凑时长。默认不变调倍率0.75–1.60，超界且无法在范围内达到目标则停止、保留文件并重新处理停顿或用同一固定音色重录。保留句内停顿；首尾检测采用10ms能量窗及60ms语音保护边缘。无需GPU即可处理已验证的既有WAV。

含数字、年份、单位或术语的句子应使用较慢档，编辑可补充terms或逐句sensitive=true。当前是整句选择较慢档，不冒称已经逐词对齐或只对某个词变速。数字读法、术语清晰度与自然度仍要听审；字速与峰值合格不等于发音已经验收。

## 字数与验收口径

排除标点，按实际读法计数，年份逐字、常规数量/小数/百分数展开后计字，包含“〇”。AI/CPU等逐字母读法按字母计数；英文单词、型号、日期范围或不确定读法须写实际spoken_text，不能按品牌拼写长短猜读音。不改变字幕文稿。

edition可用从0开始的全部句序号（含开场2句）添加读音计数注释，例如：

```json
{"speech_annotations":{"2":{"spoken_text":"按实际录音展开的读音","sensitive":true}}}
```

spoken_text只用于测量与计数，不会偷偷改写原稿或重录读音；必须与工作台读音预览/实际音频一致。若录音读错，应修正工作台读音再合成，不能只改计数骗过验收。

每句测实际WAV，计入既有0.22秒句尾留白与视频帧取整；正文及每位主播分别验收280–300，片头片尾和转场不进入正文统计。不用仅将门控发声片段相加来虚增字速，不把全片长除以稿字数替代正文验收。pipeline/render.py写speech-pacing.json；timeline保留每句pacing、实测时长及更新后的表演区间。
