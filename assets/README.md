# 制作素材

仓库里的素材按用途分目录。克隆仓库会获得整套素材，单个文件可在 GitHub 目录中直接打开和下载。

| 分类 | 文件 |
| --- | --- |
| [共享音乐](audio/music/) | 独立音频、曲名索引、校验清单与署名。 |
| [主播表情](characters/) | 小序、小禾的完整表情图和动作变体。 |
| [主播声音](voices/) | 两位主播的固定参考音频。 |
| [固定片尾](outro/) | 片尾视频、署名模板、双主播告别原声、校歌曲段和来源记录。 |
| [开屏](opening/) | 8 秒开屏、无声版本及署名。 |
| [台标与演播室标识](branding/) | 节目字标、校徽和社团标识。 |
| [栏目转场](transitions/) | 八套校园转场和参考文件。 |
| [播放器素材](player/) | 新闻播放器样式和脚本。 |

素材来源见 [CREDITS.md](CREDITS.md)。工作流配置和安装步骤见[快速开始](../QUICK_START.md)。
