# NJAU-CEA 共享音乐包 v1.1.0

本版共22首：此前3首，加本批19首可直接读取的用户提供录音。包含20个MP3和2个OGG，均保留原始字节，无转码。来源、时长、SHA256及用途见共享目录的MUSIC_MANIFEST.json。

[下载音乐包](https://github.com/lx-1203/NAU-CEA-News/releases/download/music-pack-v1.1.0/NJAU-CEA-Music-Pack-v1.1.0.zip) · [发布页与校验文件](https://github.com/lx-1203/NAU-CEA-News/releases/tag/music-pack-v1.1.0)

完整解压，将包内assets目录合并到新闻项目根目录。曲目和MUSIC_MANIFEST.json、CREDITS.txt、RIGHTS.md统一位于assets/audio/music；曲目显示名记在清单中，新增文件使用稳定ID命名。遇到同名文件先核对SHA，内容不同则保留双方。

这是独立的可选音乐资产组件，框架/skill仍为1.2.1。按各期需要选择，历史混音参数仅供参考，不自动设为每日默认配乐。原曲及录音各自保留权利，具体署名和权利记录见共享目录文档。
